# **App Name**: CoParent Finances

## Core Features:

- Child Support Input: Enter the monthly child support amount and specify which parent pays it.
- Expense Logging: Log individual child-related expenses with descriptions, amounts, and dates.
- Percentage Coverage Setting: Set and adjust the percentage of expense coverage for each parent (default is 50/50).
- Monthly Calculation: Calculate each parent's contribution for the month, based on the set percentages and logged expenses.
- Monthly Export: Export a monthly report with child support details and calculated expense contributions for each parent.
- Transaction History: Maintain a historical record of all entered child support payments and expenses.
- Smart budgeting advice: Using a financial model, advise parents about fair levels of monthly expenses for child care

## Style Guidelines:

- Primary color: Calming light blue (#A8D0E6) to evoke trust and reliability.
- Background color: Very light blue (#F1FAFF), close to white, to maintain a clean and calm aesthetic.
- Accent color: Muted orange (#E77143) to draw attention to important action items without being jarring.
- Font: 'PT Sans', a modern and humanist sans-serif font for both headlines and body, because its clean lines convey simplicity while the slight warmth in its letterforms prevents a clinical or stark appearance.
- Use simple, outlined icons related to finances, parenting, and shared responsibilities. Color them with the primary color.
- Keep the layout clean and well-organized. Prioritize readability with sufficient spacing and clear visual hierarchy. Utilize cards or containers to group related information together.
- Subtle transitions for a smooth user experience when navigating between different months or viewing transaction details.
